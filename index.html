Digital Forensics MSc project

Instagram Digital Forensics Investigation

Forensic Investigation of Instagram application data to trace user activity, collect and analyse evidence, build an activity timeline, and report findings while maintaining the chain of custody.

Objective
Recover and correlate account activity from app data
Outcome
Reconstructed a three-stage timeline of an Instagram Direct Message: message sent (T1), Unsend attempt (T2), and application restart (T4). Although the conversation disappeared from the app interface after the restart, the original message text remained in local SQLite records. This demonstrated local data persistence beyond what was visible in the application interface.
